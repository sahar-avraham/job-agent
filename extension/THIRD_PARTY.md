# Third-party code

`fillers.js` is adapted from avid-autofill, https://github.com/athervvidhate/avid-autofill,
file `src/content/fillers.js` as of September 2026. Kept: the React-safe text setter, the
custom dropdown picker and the file upload through DataTransfer. Removed: the Workday date
spinner, the drop-zone fallback, the shadow-root search and the highlight flash, which the
Greenhouse forms here do not need.
